First time opening it?

Windows

  1. Unzip the download and open Sidescatter.exe in the Sidescatter folder.
  2. If "Windows protected your PC" appears, click More info, then Run anyway.

macOS

  1. Open the .dmg and drag Sidescatter into your Applications folder.
  2. If it says it can't be opened, go to System Settings › Privacy & Security, scroll down and click Open Anyway.

Linux

  1. Unpack it: tar -xzf Sidescatter-linux-x86_64.tar.gz
  2. Run it: ./Sidescatter/Sidescatter

The warnings appear because the installers aren't code-signed yet, which costs money every year. The source code is all on GitHub if you'd like to check it or build it yourself.

See what it does

Real screens from the app, using public demo data.

Sidescatter

Everything from raw spectra to final stats

Raw spectral unmixing

Unmix straight from raw files using single-stain controls on beads or cells, and watch the result update as you change controls.

Per-cell autofluorescence

Each cell gets the autofluorescence profile that fits it best, instead of one average for the whole sample.

Gating you already know

Polygon, rectangle, ellipse, quadrant and Boolean gates, with the tools sitting right above every plot.

UMAP and FlowSOM

Run UMAP and FlowSOM clustering on any population and colour the map by any marker.

Data cleaning with a QC report

Find and remove flow-rate glitches and unstable stretches, then save a PDF report of what was removed.

Layouts and export

Arrange plots on a page and export to PDF, SVG, PNG or TIFF. Statistics export to CSV.

Built for spectral

Sidescatter reads the detectors from each file, so it works with any instrument, any number of lasers, and any detector layout.

  • Any laser and detector layout, including the 5-laser Aurora
  • FCS 2.0, 3.0 and 3.1, conventional and full-spectrum
  • Bead and cell controls, each paired with the right unstained
  • Signatures checked against published dye spectra
  • Opens FlowJo workspaces (.wsp)
  • Your data stays on your computer
